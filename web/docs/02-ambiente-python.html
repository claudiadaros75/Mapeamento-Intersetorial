1. Objetivo

Este documento registra a preparação do ambiente de desenvolvimento usado neste projeto: criação de um ambiente virtual Python e instalação das bibliotecas necessárias para trabalhar com dados geoespaciais.

2. Bibliotecas utilizadas

Biblioteca Papel
geopandas Leitura e análise de dados vetoriais (extensão do pandas)
shapely Operações com geometrias (pontos, linhas, polígonos)
pyproj Conversão de sistemas de coordenadas e projeções
pyogrio Motor de leitura/escrita de formatos vetoriais (SHP etc.)
matplotlib Criação de gráficos e mapas
pandas Manipulação de tabelas de dados

O geopandas instala automaticamente shapely, pyproj, pyogrio e pandas. O matplotlib foi instalado separadamente para visualização.

3. Criação do ambiente virtual

O projeto usa um ambiente virtual Python isolado, criado dentro da pasta do projeto: 

python3 -m venv .venv

O ambiente é ativado com: 

source .venv/bin/activate

4. Instalação das bibliotecas

Com o ambiente ativado (ou usando o caminho do interpretador): 

.venv/bin/pip install --upgrade pip
.venv/bin/pip install geopandas matplotlib

Versões instaladas na data deste registro:

  • geopandas 1.1.4
  • matplotlib 3.11.1
  • pandas 3.0.5
  • shapely 2.1.2
  • pyproj 3.7.2
  • pyogrio 0.13.0

5. Verificação do ambiente

Para conferir que tudo foi instalado corretamente: 

.venv/bin/python -c "import geopandas; print(geopandas.__version__)"

E para ver as versões completas: 

.venv/bin/pip list | grep -i -E "geopandas|matplotlib|pandas|shapely|pyproj|pyogrio"

6. Exercício: conferir os dados carregados

Com o arquivo data/ibge_malha_municipal/zipfiles/BR_Municipios_2024.zip baixado e extraído, é possível carregar a malha e responder às primeiras perguntas:

  1. Quantos municípios (ou geocódigos) há na malha de 2024?
  2. Quais são as colunas da tabela de atributos?
  3. Qual é o sistema de coordenadas (CRS) declarado no arquivo prj?
  4. Qual é a extensão (bounding box) do Brasil na malha?

A leitura é feita com: 

import geopandas as gpd

municipios = gpd.read_file("data/ibge_malha_municipal/zipfiles/BR_Municipios_2024/BR_Municipios_2024.shp")
print(municipios.shape)
print(municipios.columns.tolist())
print(municipios.crs)
print(municipios.total_bounds)

Os resultados obtidos devem ser registrados aqui neste documento à medida que os exercícios forem realizados.

7. Notas

  • O pip moderno pode recusar instalar pacotes para versões muito antigas do Python; o projeto usa Python 3.14, sem problemas.
  • Para projetos maiores, é recomendável manter um arquivo de dependências (requirements.txt) com as versões fixadas.
