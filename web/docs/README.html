1. Sobre o projeto

Este projeto é um espaço de estudo sobre georeferenciamento e análise geoespacial, tendo como material de partida as Malhas Municipais Digitais (MMD) do IBGE, na edição de 2024.

O objetivo é aprender na prática conceitos fundamentais de cartografia, sistemas de coordenadas, projeções e manipulação de dados geoespaciais, documentando todo o aprendizado em arquivos Org (formato org-mode do Emacs)

2. Decisões iniciais

  • Ano de referência: MMD 2024
  • Ferramenta principal: Python com geopandas
  • Recorte territorial inicial: todo o Brasil

4. Roteiro de estudo

O roteiro evolui conforme o projeto avança. Os primeiros passos são:

  1. Entender os dados do IBGE - o que é a Malha Municipal Digital, onde baixar, formato e características técnicas.
  2. Preparar o ambiente Python - instalar e verificar geopandas.
  3. Baixar a MMD 2024 e inspecionar o conteúdo dos arquivos.
  4. Ler a malha com geopandas e fazer as primeiras visualizações (ver primeira-exploracao).
  5. Construir mapas web com Leaflet - entender TileLayers, URLs de tiles e renderização de GeoJSON no navegador.

Cada novo tema estudado ganha seu próprio arquivo em docs/.
