#+TITLE: Dados (data/)
#+LANGUAGE: pt-br

Este diretório guarda os arquivos baixados do IBGE (Malha Municipal Digital
2024) e os produtos derivados das análises.

Há duas origens para a mesma malha, com finalidades diferentes:

- os *.zip* vêm do FTP de geociências e contêm /shapefiles/ (SIRGAS 2000,
  EPSG:4674) com a tabela de atributos completa - inclusive =AREA_KM2=. São
  a fonte de referência para análise em geopandas.
- os *.geojson* vêm da API de Malhas (v4) e já estão prontos para mapas web
  (Leaflet, MapLibre, GitHub Pages), sem precisar de conversão.

Estrutura esperada:

#+begin_src text
data/
`-- ibge_malha_municipal/
    |-- zipfiles/                ; shapefiles (ZIPs e pastas extraídas)
    |   |-- BR_Municipios_2024.zip
    |   |-- BR_Municipios_2024/
    |   `-- ...
    `-- geojsonfiles/            ; malhas da API em GeoJSON
        |-- BR_pais_2024_minima.geojson
        |-- BR_uf_2024_maxima.geojson
        `-- ...
#+end_src

* Como (re)baixar

Dois scripts irmãos, mesma interface e mesmos nomes de recorte (=pais=,
=regioes=, =uf=, =intermediarias=, =imediatas=, =municipios=). Sem argumentos,
baixam todos os seis; =--listar= mostra os recortes disponíveis.

- =scripts/commands/ibge_malha_municipal__baixar_dados_formato_shapefile.py= (FTP)
- =scripts/commands/ibge_malha_municipal__baixar_dados_formato_geojson.py= (API)

#+begin_src sh
# shapefiles, com extração para data/ibge_malha_municipal/zipfiles/<pacote>/
.venv/bin/python scripts/commands/ibge_malha_municipal__baixar_dados_formato_shapefile.py --extrair
.venv/bin/python scripts/commands/ibge_malha_municipal__baixar_dados_formato_shapefile.py uf --extrair

# geojson, escolhendo a qualidade
.venv/bin/python scripts/commands/ibge_malha_municipal__baixar_dados_formato_geojson.py --qualidade minima
.venv/bin/python scripts/commands/ibge_malha_municipal__baixar_dados_formato_geojson.py uf municipios
#+end_src

O script de GeoJSON completa cada feição com nome, sigla e códigos dos
recortes superiores, consultando a API de Localidades (a API de Malhas
devolve apenas =codarea=).

O script de shapefile retoma downloads interrompidos, confere o tamanho
local contra o do servidor antes de pular um arquivo, e com =--extrair=
descompacta em =data/ibge_malha_municipal/zipfiles/<pacote>/= - o layout que =scripts/commands/ibge_malha_municipal__explorar_shapefiles.py=
espera.

* Qualidade da malha (API)

A API generaliza a geometria em três níveis. Tamanhos medidos para a malha
municipal do Brasil inteiro:

| qualidade     | tamanho |
|---------------+---------|
| minima        |  5,3 MB |
| intermediaria | 15,1 MB |
| maxima        | 64,2 MB |

Para publicar no GitHub Pages, prefira =minima= (ou =intermediaria=): 64 MB
de GeoJSON travam o navegador e o repositório.

* O que vai para o repositório

Todo o conteúdo de =data/= é reproduzível pelos scripts, então o =.gitignore=
mantém versionado apenas o que é leve o bastante para o GitHub Pages:

| Arquivos                                                     | Versionado | Como recuperar                          |
|--------------------------------------------------------------+------------+-----------------------------------------|
| =ibge_malha_municipal/zipfiles/*.zip= (shapefiles, ~350 MB)  | não        | script de shapefile                     |
| =ibge_malha_municipal/geojsonfiles/*_maxima.geojson=         | não        | script de GeoJSON, =--qualidade maxima= |
| =ibge_malha_municipal/geojsonfiles/*_minima.geojson=         | sim        | -                                       |
| =ibge_malha_municipal/geojsonfiles/*_intermediaria.geojson=  | sim        | -                                       |

São cerca de 23 MB versionados, contra ~480 MB no total.
